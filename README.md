# Dual Subtitle — *DARK SOULS III*

NPC dialogue and cutscene subtitles in Chinese and English on one line: `中文` / `English`.
Text only.

| | |
| --- | --- |
| NPC dialogue | `中文` + `English` |
| Cutscene subtitles | `中文` + `English` |
| Area name shown after warping | English, in both language modes |

Base game and both DLC. Every other text stays vanilla.

**English** · [中文](#中文)

---

## English

### Install

Point one of the mod loaders at this package's `msg` folder — [me](https://www.nexusmods.com/darksouls3/mods/2410), [me2](https://github.com/soulsmods/ModEngine2) or [me3](https://github.com/garyttierney/me3). Start the game offline.

### Uninstall

Delete the mod's `msg` folder.

### Notes

- Text only. If another mod also replaces `msg`, load order decides.
- A merged line can wrap to three lines and sit tight against the bottom of the dialogue box.
- The area title is drawn on one line and cannot be made bilingual without cutting the tail off long names, so it stays English.

## 中文

### 安装

用 [me](https://www.nexusmods.com/darksouls3/mods/2410)、[me2](https://github.com/soulsmods/ModEngine2)、[me3](https://github.com/garyttierney/me3) 其中一个指向本包的 `msg`。装完离线启动。

### 卸载

删掉本包的 `msg`。

### 注意

- 只改文本。别的 mod 也换 `msg` 时，看加载顺序。
- 合并后的行可能折到三行，个别对话会顶到对话框下沿。
- 地名标题是单行、不能缩字号，双语会把长名字的尾巴切掉，所以固定显示英文。
